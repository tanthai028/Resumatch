# resumes/

Put your resume PDFs here, named exactly as `filename` in `config.json`:

- `Tan_Thai_Resume_Software.pdf`
- `Tan_Thai_Resume_Tech_Support.pdf`
- `Tan_Thai_Resume_IT_Support.pdf`
- `Tan_Thai_Resume_Business_Analyst.pdf`

The application log links each entry to the file you sent, so you can open or
download it again. Reload the extension in `chrome://extensions` after adding
files.

PDFs in this folder are ignored by git (see `.gitignore`), so your resumes are
not committed or pushed.
